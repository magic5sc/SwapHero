# PixelFX 表演预览

测试台 `tests.html` 提供横版 `pixelfx-preview.html` 和纵版 `pixelfx-vertical.html`。两页使用现有教会剑士、骑士和弓手图集，提供斩击、飞行火球及爆炸、冰霜新星、治疗、护盾。支持重播、暂停、1/4–1.5 倍速度、逐帧、时间条、配色、角色朝向镜像与特效开关。

两版直接加载项目战斗样式，包括桌面、皮革场景、计分栏、十二个半透明格位、编号、攻血数值和生命条。纵版从上到下为对手备战、对手战场、我方战场、我方备战，出演角色原地攻击，目标向上受击。横版从左到右为我方备战、我方战场、对手战场、对手备战，每列三个格位；斩击向右突进，火球向右飞行，目标向右受击。两版采用同一套本地格序和预览队伍。

`src/pixelfx-preview.mjs` 共用一个时间轴，从实际格位读取角色、命中和施法锚点，视口变化后重新测量。拖动时间条重建固定种子实例并按 1/120 秒步进，后层、角色、前层顺序合成。治疗和护盾使用当前角色轮廓。隐藏标签暂停时间推进，减少动态偏好默认暂停。默认使用皮革，也可切换浮岛或暗底。两页为独立表演，不读写冒险存档、编辑器或正式技能配置，游戏专用构建排除两页及其专用资源。

## 光矛合并与锚点修正（2026-11-06）
纵向页增加螺旋光矛，?effect=spear 可直接选中；旧 photon-spear.html 自动跳转，测试台链接同步。
共享预览脚本从待机图透明像素提取可见顶部/底部及头部中轴，按实际裁剪比例、镜像与布局尺寸转换为身体和脚底坐标，避免把包含武器伸展与留白的图片框当身体中心。
刀光以主刃尖局部坐标补偿（中心6,-26、半径38.4、角度.95、倾斜-.38），命中点跟随受击回退；火球与爆炸中心共享目标身体点；冰环与治疗对准脚底；护盾局部CY=-22补偿到身体点，贴身遮罩相对同一原点生成。
光矛增加distance参数，按双方身体锚点计算距离和角度；命中爆炸不再固定100像素飞行。修复1/120步进浮点尾差导致准确命中时刻仍显示飞行帧。
验证：202项Node回归通过；Chrome六效果×三角色、旧链接跳转、刀光刃尖/光矛终点/脚底/护盾中心坐标误差<0.01px、镜像后同刻回拖一致、390px无横向溢出通过。手机实机及负责人视觉验收待完成。

## 冒险开箱

普通和精英战斗胜利后的宝箱使用 [PixelFX Chest Open](https://github.com/patch-gg/pixelfx/blob/a84159688af3ca37a4be05a0d422b94451b2e24e/src/fx/pickups/chest-open.js)。`chest-fx.mjs` 按官方预览的 1 倍速和效果声明的 30 帧每秒播放完整的 4.6 秒时间轴，由 PixelFX 内部推进模拟。精英宝箱使用银色光效。点击时先保存 `chestOpened`，随后播放开箱和原有奖励翻牌。已开箱的存档直接展示奖励。减少动态效果模式使用静态宝箱并直接展示奖励，Canvas 不可用时使用原有宝箱图。

game-only 构建保留 PixelFX 核心、许可、开箱特效与其 `_lib.js`，其余预览专用效果仍只进入开发版和统一站点。
