# PixelFX 表演预览

测试台 `tests.html` 的 PixelFX 按钮进入 `pixelfx-preview.html`。使用现有教会剑士、骑士和弓手图集，配合五段预览编排：斩击、飞行火球及爆炸、冰霜新星、治疗、护盾。支持重播、暂停、1/4–1.5倍速度、逐帧、时间条、配色、镜像与特效开关。

这是独立展示页，不导入战斗、存档或编辑器模块，不改变正式技能配置。角色动作取自现有图集，预览时间轴不代表已验收的正式技能动作。默认使用项目皮革战场，可切换已有浮岛场景或检查光效的暗底。game-only构建排除本页及vendor/pixelfx。

`src/pixelfx-preview.mjs` 以同一时间轴驱动角色、粒子与进度条。拖动时间条重建固定种子实例并按1/120秒步进，后层、角色、前层顺序合成；治疗和护盾传入当前角色透明轮廓，不显示上游示例灰人。隐藏标签暂停时间推进，减少动态偏好默认暂停。没有保存或联网运行依赖。
