# 普攻位移 A/B 独立试演

入口 `dist/attack-motion.html`，测试台提供入口。正式战斗、选敌、普攻频率与存档均不改变。

- A：只有角色画面沿真实目标向量短突进，卡牌留在原位。
- B：整张角色卡牌沿相同向量接近目标、碰撞、归位。
- 三个固定夹具：直线、相邻斜向、最远对角。手动选定目标不代表正式战斗选敌规则。
- 两版统一 1.2 秒节奏，0.48 秒命中。支持骑士/剑士、0.5 倍速、时间轴、辅助线开关、三目标连续播放。
- 固定伤害 4，仅显示演示 HP；不读写任何存档。

验证：编译 PVE/教学成功；串行 Node 测试 212/212 通过（含 4 项新增运动模型测试）；浏览器检查素材、A/B 切换、对角命中和时间轴。独立页面尚未接入正式战斗结算队列。移动端 CSS 已适配，未做真机验证。

## PixelFX 剑刃斩击

用户选择选项 2：A 预览接入既有 `sword-slash.js`，默认开启、支持开关。命中前 0.06 秒起播，沿原始刀光刃尖补偿锚点对准目标，0.48 秒伤害和命中同步。目标效果按实际攻击向量旋转并跟随目标回退，自身角色及其原有动作保持朝向，不旋转。B 保持原始冲撞演示。独立效果画布支持暂停、反向拖动重建和固定种子回放。

验证：方向和时间模型新增 2 项测试；浏览器验证直线、相邻斜向、最远对角的旋转分别随实际布局计算，回拖和目标锚点正常。仍未改正式游戏或存档。

## 正式战斗接入

用户确认“把这个做进正式版吧，我觉得效果不错”。`normal-attack-presentation.mjs` 只接收现有结算帧，不参与规则。正式双方普攻沿 `f.targetLane` 对应的真实屏幕坐标短突进，只移动角色，不移动卡框/数值、不旋转角色。原 CSS 整卡纵向抖动在正式战斗中关闭；角色动作仍由原序列/骨骼播放器驱动。

未指定普攻特效和旧 slash 配置使用已认可的 PixelFX 剑刃斩击；显式 fireball/burst 保留原配置，不修改角色数据。刀光按源→目标向量旋转，锚定目标身体；击溃后仍只显示刀光，不重建死亡角色。空目标得分不产生目标刀光。支持减少动态效果偏好，演出结束清除 canvas 与位移。

保持既有节奏：序列角色攻击640ms+命中600ms，其他角色360ms+500ms；选敌、伤害、死亡移除、触发链、顺序、行动锁和存档完全沿用。正式 game-only 包新增保留刀光渲染器及其依赖。

验证：217项Node测试通过；PVE/教学编译与game-only构建通过。浏览器执行教学战斗双方回合，确认伤害、动作锁、目标刀光、回合恢复，结束后无残留特效或translate。方向数学测试覆盖双方/对角，预览已验证三线路；手机真机与正式战斗窄屏未实测。
