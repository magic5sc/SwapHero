# 教会弓手可选角色

在既有 PvE 0.5.0 基础上增加 `temple_archer`（教会弓手）。用户已确认光头、面巾、皮甲静态 v3 和足部锁定序列帧 v2，并授权接入角色库。

编辑器“引用角色”可选，兼容已有本地草稿；不替换现有卡牌引用。角色使用独立序列图集、6帧待机与8帧攻击，192×192画布，待机2000ms、攻击1320ms。两组动作均保持双脚固定，释放帧开始于730ms。伤害仍由已有战斗规则结算。

通用序列渲染按角色加载图集和时长，保留剑士原动画。素材及生成提示词位于 dist/assets/characters/temple-archer。旧美术实验不进入发布包。

验证：角色库迁移、引用校验、动画时序及两角色图集尺寸自动测试；浏览器与手机完整实战验收另行记录。
